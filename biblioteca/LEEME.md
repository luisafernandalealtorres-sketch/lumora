# Biblioteca

**Cómo usarla**
- Artículo: pega el texto o el enlace. Video: pega la transcripción o tus notas. Libro: subrayados, notas o PDF.
- Yo creo `biblioteca/AAAA-MM-DD-titulo.md` con la plantilla de abajo.
- Para consultar: "¿Qué decía ese video sobre X?" Busco primero aquí y cito el archivo.

## Plantilla de ficha
```
# Título
Fuente: (enlace, autor, tipo: artículo | video | libro)
Fecha guardado:
Etiquetas: #tema #frente

## Resumen (5 líneas)
1.
2.
3.
4.
5.

```
